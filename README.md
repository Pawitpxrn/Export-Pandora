# 📑 PDF to Excel Custom Converter (ระบบแปลงรายงาน PDF เป็น Excel ตามหัวข้อที่ต้องการ)

ระบบช่วยแปลงไฟล์รายงานที่เป็น PDF ให้เป็นไฟล์ Excel (.xlsx) อย่างเป็นระเบียบ โดย **ยึดข้อมูลและหัวข้อจากไฟล์ต้นทาง** พร้อมทั้งให้คุณสามารถ **เลือกเฉพาะคอลัมน์ที่ต้องการ** และ **ปรับเปลี่ยนชื่อหัวข้อภาษาไทย/อังกฤษ** ได้ตามใจชอบ

---

## ✨ ความสามารถหลักของระบบ (Features)

1. **Auto-Detection ตารางและหัวข้อ**: อ่านโครงสร้างตารางและหัวข้อจากไฟล์ PDF อัตโนมัติ รองรับรายงานแบบหลายหน้า (Multi-page tables)
2. **คัดเลือกเฉพาะหัวข้อที่ต้องการ**: เลือกเฉพาะคอลัมน์ที่ต้องการใช้งาน หรือจัดเรียงลำดับใหม่ได้ทันที
3. **กำหนดชื่อหัวข้อ (Mapping)**: สามารถเปลี่ยนชื่อหัวข้อใน Excel ปลายทาง หรือคงตามชื่อต้นทางใน PDF ไว้ได้
4. **บันทึกโพรไฟล์ (Profile Presets)**: สำหรับรายงานประจำรอบ สามารถกดบันทึกการตั้งค่าไว้ เพื่อใช้งานซ้ำได้ใน 1 คลิก
5. **แปลง Data Types อัตโนมัติ**: ตัวเลขที่มีลูกน้ำ คั่นจุลภาค ยอดเงิน ติดลบแบบวงเล็บ `(1,000.00)` จะถูกแปลงเป็น Number จริงใน Excel เพื่อนำไปคำนวณต่อได้ทันที
6. **หน้าตา Excel ระดับมืออาชีพ**: มีสีหัวตารางชัดเจน (Navy Blue), เส้นกรอบ, ตัวหนา, Auto-Filter, ปรับความกว้างคอลัมน์พอดีข้อความ และ Freeze แถวหัวตาราง
7. **ใช้งานได้ทั้ง 2 รูปแบบ**:
   - **Web UI (Streamlit)**: เปิดในเบราว์เซอร์ ลากไฟล์วาง ดูพรีวิว และกดดาวน์โหลด
   - **Command-Line (CLI)**: สคริปต์สำหรับรันแปลงไฟล์แบบอัตโนมัติ

---

## 🚀 วิธีเริ่มต้นใช้งาน

### 1. เปิดใช้งานผ่านหน้าเว็บ (Web UI - แนะนำ)
ดับเบิลคลิกไฟล์:
```
run_app.bat
```
หรือรันคำสั่งผ่าน Command Prompt / PowerShell:
```powershell
& "C:\Python312\python.exe" -m streamlit run app.py
```
เบราว์เซอร์จะเปิดหน้าเว็บ `http://localhost:8501` ขึ้นมาโดยอัตโนมัติ

### 2. ขั้นตอนบนหน้าเว็บ
1. ลากไฟล์ PDF ที่ต้องการแปลงมาวางในช่อง **"เลือกไฟล์รายงาน PDF"** (สามารถเลือกหลายไฟล์พร้อมกันได้)
2. ระบบจะอ่านข้อมูลและแสดงจำนวนแถว คอลัมน์ที่พบ
3. ในหัวข้อ **"เลือกหัวข้อและตั้งค่าคอลัมน์ Excel"**:
   - ติ๊กเลือกเฉพาะคอลัมน์ที่ต้องการ
   - พิมพ์เปลี่ยนชื่อหัวข้อในช่องปลายทาง (หรือปล่อยไว้ตามเดิม)
4. ตรวจสอบข้อมูลในตาราง **Preview**
5. กดปุ่ม **"🟢 ดาวน์โหลด Excel"**

---

### 3. ใช้งานผ่าน Command Line (CLI)

```powershell
# แปลงไฟล์ PDF ทั่วไป
& "C:\Python312\python.exe" cli.py --input "path\to\report.pdf" --output "path\to\output.xlsx"

# แปลงไฟล์โดยใช้ Profile ที่บันทึกไว้ (เช่น sales_summary_only)
& "C:\Python312\python.exe" cli.py --input "path\to\report.pdf" --profile "sales_summary_only"
```

## 📁 โครงสร้างโปรเจกต์

```text
pdf-to-excel-converter/
├── app.py                  # หน้าเว็บ Streamlit แบบ Interactive
├── cli.py                  # โปรแกรมรันผ่าน Command-Line
├── run_app.bat             # ไฟล์ดับเบิลคลิกเปิดโปรแกรมทันที
├── test_converter.py       # ชุดทดสอบระบบอัตโนมัติ (pytest)
├── core/
│   ├── extractor.py        # เครื่องมือแกะข้อมูลตารางและข้อความจาก PDF
│   ├── excel_builder.py    # เครื่องมือจัดรูปแบบและสร้างไฟล์ .xlsx
│   ├── normalizer.py       # ตัวแปลงชนิดข้อมูล (ตัวเลข, วันที่, ข้อความ)
│   └── profile_manager.py  # ระบบบันทึก/โหลดโพรไฟล์การจับคู่หัวข้อ
├── profiles/               # โฟลเดอร์เก็บโพรไฟล์การตั้งค่าคอลัมน์ (.json)
└── samples/                # ไฟล์ตัวอย่างรายงาน PDF สำหรับทดสอบ
```
